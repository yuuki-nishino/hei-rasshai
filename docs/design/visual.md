# 見た目の設計

画面の雰囲気・色・文字・余白と、共通部品の見た目を決める（#29）。各画面（#7〜）は、これに沿って作る。要件は [SPEC.md](../SPEC.md) §7.5、画面ごとの設計は [screens.md](./screens.md)。

## 1. 方針

- **雰囲気**：屋台の明るさと、野外の自然な感じ。ただし、どんなイベントでも使えるよう、派手にしすぎない
- **基調**：弁柄（茶色がかった赤）× 生成り（きなりの紙の色）。差し色に、苔の緑
- **モチーフ**：画面の上の帯を「のれん」に見立て、下の端に切れ目を3本入れる（`Noren`）
- **状態の色が主役**：調理中・できあがり・取り消し・支払いの色が、基調の上で目立つようにする。基調の赤は、取り消し（赤）・PayPay（赤系）と混ざらないよう、茶色寄りにずらす
- 屋外・立ち仕事：大きな文字、44px 以上のボタン、高いコントラスト（文字は 4.5:1 以上、入力欄の枠は 3:1 以上）
- 決めるときに、taste-skill（Leonxlnx/taste-skill、MIT）を参考にした。スキルとしては入れていない（ランディングページ向けで、React・Tailwind・Webフォントが前提のため）。取り入れたのは、色の選び方（落ち着いた基調＋強い差し色）、ボタン・入力欄のコントラストの点検、`prefers-reduced-motion` の尊重

## 2. 決まり（`src/styles/tokens.css`）

色・文字・余白は、`tokens.css` の CSS変数だけを使う。部品のCSSに、色の値を直接書かない（例外：`dangerSolid` の白い文字）。

### 色

| 変数 | 値 | 使い道 |
|---|---|---|
| `--color-bg` | `#f5f0e6` | 画面の地（生成り） |
| `--color-surface` | `#fffdf8` | カード・入力欄・ダイアログ |
| `--color-ink` / `--color-ink-sub` | `#2b2622` / `#6f655b` | 文字 / 補足の文字（地との差 5.0:1） |
| `--color-line` / `--color-line-strong` | `#e2d8c8` / `#8c7d6c` | 区切り線・カードの枠 / 入力欄・副ボタンの枠（3.9:1） |
| `--color-brand` / `--color-on-brand` | `#a63a24` / `#fff8ef` | 弁柄：のれん・主のボタン・ロゴ（6.1:1） |
| `--color-nature` / `--color-nature-bg` | `#5e6b3a` / `#e7e9d6` | 苔：タブ・ロゴの下の線 |
| `--color-focus` | `#1f5fbf` | フォーカスの輪 |

状態・支払いは、地の色と文字の色の組（`--status-*-bg` / `--status-*-fg`、`--pay-*`）。色だけに頼らず、必ず文字（「調理中」など）と、状態には点を添える。

| 状態・支払い | 地 / 文字 | 文字との差 |
|---|---|---|
| 調理中（黄） | `#fbe7a1` / `#5f4500` | 7.3:1 |
| できあがり（緑） | `#cbe8c6` / `#1d5427` | 6.8:1 |
| お渡し済み（グレー） | `#e3e2dd` / `#4f4d48` | 6.5:1 |
| 取り消し（赤） | `#f6d0cc` / `#8f1d1d` | 6.3:1 |
| 現金（黄系） | `#fff0bf` / `#6e4f00` | 6.6:1 |
| PayPay（赤系） | `#d42a35` / `#ffffff` | 5.0:1 |

- 接続状態（`StatusBar`）も、同じ組を使う（オンライン＝できあがりの緑、オフライン＝取り消しの赤、未送信あり＝調理中の黄）
- **ライトのみ**（`color-scheme: light`）。屋外では、明るい画面の方が見やすいため。ダークモードは作らない（必要になったら、変数を差し替える形で足せる）

### 文字

| 役 | 文字 | 例 |
|---|---|---|
| 見出し・ボタン・注文番号・ロゴ | **Zen Kurenaido**（手書き、筆ペン風。SIL OFL） | 「注文を受ける」「確定する」「24」 |
| 本文・金額・補足・入力 | 端末の文字（`system-ui`、ヒラギノ、Noto Sans JP など） | 「焼きそば ×2」「1,200円」 |

- Zen Kurenaido は、太さが1つ（400）しかない。太くしたいところ（ロゴ・主のボタン・のれんの見出し・ダイアログの見出し）は、**同じ色の縁取り**（`-webkit-text-stroke`）で太く見せる。幅は `--hand-bold`（0.035em）、ロゴは 0.05em。共通のクラス：`.hand`（細）、`.hand-bold`（太）
- 金額や表の数字は、読み間違いを防ぐため、手書きにしない
- 大きさ：13 / 14 / 16（本文）/ 19（ボタン）/ 24（見出し）/ 32（注文番号）/ 40px（ロゴ）。入力欄は 16px 以上（iPhone が入力時に拡大しないため）

#### フォントの読み込み（スタッフ画面だけ）

- `@fontsource/zen-kurenaido` を、自分のサイトから配信する（外部のフォント配信を使わない。CSPやオフラインのため）
- 日本語のフォントは大きいため、文字の範囲ごとに約120のファイルに分かれている（`unicode-range`）。ブラウザは、**画面に出ている文字のファイルだけ**を読み込む（初回は数百KB、2回目からはキャッシュ）
- 範囲の定義のCSS自体も大きい（gzip後 約63KB）ため、`src/staff/main.tsx` で、**画面を出した後に**読み込む（`import()`）。届くまでは端末の文字で表示し、届いたら切り替わる（`font-display: swap`）
- `dist/` には、woff2 と woff（古いブラウザ用）の両方が入る（約5MB）。Hosting の容量（10GB）には十分収まる。ホーム画面アプリ（M7）で、Service Worker の事前キャッシュに入れるかは、そのときに決める（全部入れると重い）
- **お客様画面は、Webフォントを使わない**（screens.md §4.3）。`src/customer/customer.css` で、手書きの役（`--font-hand`）を端末の文字に置き換える

### 余白・角・影

- 余白：4px 刻み（`--sp-1`〜`--sp-10`：4・8・12・16・20・24・32・40px）
- 角：8px（入力欄）/ 14px（ボタン・カード）/ 20px（ダイアログ）/ 丸（バッジ）
- 影：カードは、ごく薄く。**主のボタンだけ、下に厚み**（`--shadow-raised`。木札のような手触り）があり、押すと沈む。ダイアログ・トーストは、浮かせる
- 押せる部分：44px 以上（`--tap-min`）、大きいボタンは 56px（`--tap-big`）
- 動き：160ms 以内。`prefers-reduced-motion` のときは、止める

## 3. 共通部品（`src/components/`）

CSS は、部品ごとに CSS Modules（`*.module.css`）で書く（[ADR-0006](../adr/0006-plain-css-modules.md)）。

| 部品 | 内容 |
|---|---|
| `Button` | `primary`（弁柄で塗り、太字、厚み。1画面に1つ）/ `secondary`（白地に枠）/ `danger`（白地に赤い枠と文字。取り消し・削除。押したら確認ダイアログ）/ `dangerSolid`（確認ダイアログの中の実行）。`big`（56px）、`block`（横幅いっぱい） |
| `StatusBadge` / `PaymentBadge` | 状態（点＋文字）・支払いのバッジ。値は data-model.md の `status` / `payment` |
| `Card` | 1件ずつのまとまり。`muted`：お渡し済み・取り消しなど（薄くせず、地の色にして、文字のコントラストを保つ） |
| `TextField` | ラベル・補足・エラーを、入力欄に結び付ける（`aria-describedby`・`aria-invalid`）。数字は `inputMode="numeric"` |
| `ConfirmDialog` | ブラウザ標準の `<dialog>`（フォーカスの閉じ込め・Esc で閉じる）。「やめる」を左、実行を右に離して置き、最初のフォーカスは「やめる」 |
| `Toast` / `ToastRegion` | 画面の下に重ねる。失敗は赤地で、閉じるまで残す。消す時間の管理は、使う側（後のIssueの ToastHost）で行う |
| `StatusBar` | 接続状態の帯（オンライン／オフライン／未送信◯件・未送信あり） |
| `Noren` | 画面の上の帯（のれん）。見出し・補足・右端の操作。iPhone の上の切り欠きの分、余白を足す |
| `Logo` | イベント注文アプリ「毎度おおきに」 |
| `Loading` / `Empty` / `ErrorView` | 読み込み中・0件・取得失敗 |

## 4. ロゴ

- 上に小さく「イベント注文アプリ」（補足の文字の色、字間を空ける）、下に大きく「**毎度おおきに**」（手書き・太・弁柄、40px）、その下に苔色の短い線
- ブラウザの上の色（`theme-color`）は、弁柄（`#a63a24`）。のれんとつながって見える

## 5. 部品の見本（`/#catalog`）

- 部品と色・文字を一覧するページ。**dev とローカルだけ**で開ける（`import.meta.env.MODE !== 'production'`。本番のビルドには、コードごと含まれない）
- ログインは不要（データを読まない）。実機の見た目は、dev の `https://maido-ookini-dev.web.app/#catalog` で確かめる
- 開いた後に、アドレスの `#catalog` を付け外ししたときは、再読み込みする
