# 設計レビューへの対応

[設計レビュー](./design-review.md) の各指摘について、反映するもの・一部反映するもの・見送るものを、理由とともに整理する。

- 判断：**採用**＝指摘どおり反映／**修正して採用**＝方針は採用し、やり方を変えた／**一部採用**＝一部だけ反映／**見送り**＝反映しない
- 反映先の略称：DM＝`design/data-model.md`、SR＝`design/security-rules.md`、DA＝`design/data-access.md`、OC＝`design/order-confirm.md`、SC＝`design/screens.md`、TS＝`design/testing.md`、DS＝`DESIGN.md`
- 反映した内容は、レビューの根拠（SDKやルールの挙動）を、すべて実機・Emulatorで確かめたものではない。確認が要るものは、★の検証項目（R1〜R11、W1・W2、F1）として、設計書に残した
